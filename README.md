# دروسك بلس — دخول جروب المشتركين بالكود

## ما الذي تم إضافته
- الطالب يرسل `/group` للبوت الخاص (أو يضغط Start ثم يكتب `/group`).
- إذا كان Telegram ID مربوطًا بكود فعّال، البوت يرسل رابط دعوة خاصًا يطلب الانضمام.
- إذا لم يكن مربوطًا، يطلب البوت كود الاشتراك. يتم التحقق من الكود مباشرة من قاعدة المنصة، ثم ربطه بحساب Telegram.
- عند وصول `chat_join_request` للجروب المحدد، البوت يتحقق من الاشتراك مرة أخرى ويقبل الطلب فقط إذا كان الكود ما زال فعالًا.
- الكود الموقوف أو المنتهي لا يُقبل. الكود غير المفعّل بعد (expiresAt فارغ) يُسمح به إذا كان موجودًا وغير موقوف.
- لا يتم قبول أي طلب إذا لم يتم ضبط `SUBSCRIBERS_GROUP_ID`.

## النشر
1. للحصول على معرف الجروب، أضف البوت والأدمن للجروب، ثم اكتب `/groupid` داخل الجروب من حساب الأدمن؛ البوت يرد بمعرف الجروب.
2. خدمة البوت: استبدل `server.js` بملف `bot/server.js`، واحتفظ بملف `public/index.html` و`package.json` الحاليين.
3. خدمة المنصة: استبدل ملف السيرفر الحالي بملف `platform/server.js` (هو نفس ملف المنصة مع endpoint التحقق الجديد).
4. اعمل Deploy للخدمتين.
5. أضف متغيرات Railway التالية إلى خدمة البوت:
   - `SUBSCRIBERS_GROUP_ID`: معرف الجروب الخاص، غالبًا يبدأ بـ `-100`.
   - `PLATFORM_API_URL`: رابط خدمة المنصة الأساسي بدون `/` في النهاية.
   - `BOT_TRIAL_SECRET`: نفس القيمة الموجودة في خدمة المنصة.
   - احتفظ بمتغيرات البوت الحالية: `BOT_TOKEN`, `WEBHOOK_SECRET`, `ADMIN_PASSWORD`, `ADMIN_USER` إن كنت تستخدمه.
5. في خدمة المنصة، تأكد من وجود `BOT_TRIAL_SECRET` بنفس القيمة بالضبط.
6. أضف البوت للجروب كأدمن، وامنحه صلاحية إدارة روابط الدعوة وقبول/رفض طلبات الانضمام.
8. اجعل الجروب خاصًا. الطالب يفتح البوت الخاص أولًا، يرسل `/group`، ثم يكتب كود اشتراكه إذا طُلب منه.

## ملاحظات مهمة
- لا ترسل رابط الجروب العام؛ البوت ينشئ رابط طلب انضمام محدود الصلاحية (24 ساعة) لكل طالب بعد التحقق.
- Telegram لا يسمح للبوت بمراسلة الطالب خاصًا قبل أن يبدأ الطالب البوت. لذلك على الطالب الضغط على Start وإرسال `/group` أولًا.
- عند إدخال الكود لأول مرة، يتم ربط الكود بمعرف Telegram. لو الكود مربوط بحساب Telegram آخر، يرفض التحقق.
- اختبر على حساب طالب تجريبي وكود فعّال قبل مشاركة الرابط مع الطلاب.
