# دروسك بلس — Telegram Business Auto Reply

## الملفات
- `server.js`: Telegram Business webhook، الردود، مسار صورة التحويل اليدوي، تجربة المنصة، إشعارات الإدارة، ومطابقة الصور المرجعية.
- `public/index.html`: لوحة التحكم لإدارة الكلمات المفتاحية والردود والصور المرجعية.
- `package.json`: تشغيل Node.js + Express.

## Railway Variables
احتفظ بالمتغيرات الحالية واضبطها بالقيم الصحيحة:
- `BOT_TOKEN`: توكن البوت.
- `ADMIN_USER`: اسم مستخدم لوحة التحكم.
- `ADMIN_PASSWORD`: كلمة مرور قوية.
- `ADMIN_TELEGRAM_ID`: Telegram ID الصحيح لحساب الإدارة (لا تعتمد على القيمة الافتراضية).
- `WEBHOOK_SECRET`: سر webhook.
- `DATA_FILE=/data/replies.json`
- `PLATFORM_API_URL`: رابط سيرفر المنصة بدون `/` في النهاية.
- `BOT_TRIAL_SECRET`: سر التكامل مع API المنصة.
- `OPENAI_API_KEY`: اختياري، مطلوب لمطابقة الصور المرجعية.
- `RAILWAY_PUBLIC_DOMAIN`: يضبطه Railway تلقائيًا عند تفعيل الدومين العام.

اربط Volume على `/data` حتى لا تضيع الردود وسجلات الطلبات عند إعادة التشغيل.

## سلوك الصور والتحويل
- عند استلام صورة، البوت يحفظ سياقها ولا يطلب رقم التحويل تلقائيًا.
- يمكنك الرد على صورة الطالب من حساب Telegram Business بكلمات مثل «اشتركتك» أو «دي رسالة التحويل» أو «أنا حولت». البوت يبدأ بعدها سؤال وقت التحويل، ثم يطلب رقم الهاتف والاسم والشعبة.
- اترك «رد الصور» فارغًا إذا كنت تريد الرد بنفسك من الموبايل.
- الصور المرجعية من لوحة الأدمن تُستخدم لاختيار رد مشابه بصريًا عند توفر `OPENAI_API_KEY`. هذا لا يثبت وصول الأموال.
- الإدارة يجب أن تتحقق من وصول المبلغ فعليًا قبل الموافقة على الاشتراك.

## التجربة
البوت يرسل Telegram ID إلى API المنصة عند طلب التجربة. منع إعادة التجربة للأكواد القديمة يجب أن يكون مفروضًا في API المنصة/قاعدة البيانات أيضًا؛ Telegram Bot API لا يتيح للبوت قراءة تاريخ الشات كاملًا للتحقق من كل كود أُرسل يدويًا قبل تشغيله.

## النشر
1. استبدل `server.js` و`public/index.html` في نفس مستودع GitHub المرتبط بـ Railway.
2. تأكد أن `package.json` يحتوي `npm start` ويستخدم Node 20 أو أحدث.
3. تأكد من وجود Volume على `/data` والدومين العام.
4. اعمل Commit وانتظر Deploy.
5. افتح `/admin` وسجل الدخول.

## أمان
لا تشارك `BOT_TOKEN` أو `ADMIN_PASSWORD` أو `WEBHOOK_SECRET` أو `BOT_TRIAL_SECRET` أو `OPENAI_API_KEY`.
